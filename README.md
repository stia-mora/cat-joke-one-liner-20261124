An entry for the make.fun bounty "The One-Line Cat Joke That Lands". The program writes one original cat joke to `/output/entry.txt`: a cat who ignores his human all day, then wakes him at 3 a.m. screaming at a door that is already open. Setup, turn, no padding, no explanation afterwards — the kind of line you would actually retell to a friend the same day.

## Run it

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` (a single line, under 200 characters).
